# V4 接口合同

下列路径均相对于 `/api/v3`。除健康和登录外均使用 Bearer。除账号自读外，资源操作要求招聘角色。Demo 复用招聘合同，账号写入只在正式模式开放。

所有读取无请求体。未列出查询参数表示合同未提供筛选。分页返回 `items,total,limit,offset` 等分页字段，历史返回项与 `nextCursor`，游标的两个参数须一并提供。创建写入首次成功通常 201，更新及重放 200，业务命令返回 `{replayed,result}`。写入须使用 JSON 与 `Idempotency-Key`，已有聚合还需 `expectedVersion`。同键同请求重放，同键异请求冲突。面试和面评另外校验对应版本。认证写入按账号版本并发校验，独立于招聘幂等回执。

| 方法与路径 | 输入 | 响应及限制 |
| --- | --- | --- |
| GET /health | 无 | `{status}`，公开 |
| POST /auth/login | username、password、可选 remember | token、expiresAt、user，12 小时或 7 天 |
| GET /auth/me | 无 | id、username、name、role |
| PATCH /auth/me | name | 更新后的当前用户 |
| PATCH /auth/me/password | currentPassword、newPassword | 204，撤销旧令牌 |
| GET /dashboard/summary | 无 | now、timezone、openPositions（含 softDeletedOpen）、activeApplications、todayInterviews、applicationTotals、work、offerByStatus |
| GET /dashboard/history-metrics | 无 | now、timezone、applications、offer。申请按 appliedDate 统计七个自然月，Offer 按 occurredAt 聚合当月真实事件，两者分别返回覆盖状态 |
| GET /dashboard/work-items/:type | limit、offset | 待办分页，type 为 screening/scheduling/due/feedback/decision/offer |
| GET /dashboard/offer-work-items/:status | limit、offset | preparing/sent/accepted 子状态分页 |
| GET /dashboard/today-interviews | limit、offset | 北京自然日面试及到时提示 |
| GET /positions | q、status、limit、offset | 职位分页与申请记录统计 |
| GET /positions/options | 无 | 可供申请关联的职位选项 |
| GET /positions/:positionId | 无 | 职位详情、归档及关联统计 |
| POST /positions | title、department、location、publishDate、description | 业务回执 |
| PATCH /positions/:positionId | 同上可更新字段 | 业务回执 |
| POST /positions/:positionId/status | status 为 open/closed | 业务回执 |
| POST /positions/:positionId/archive | 通用版本字段 | 归档回执 |
| GET /applications | q、positionId、stage、applicationStatus、limit、offset | 申请分页 |
| GET /applications/:applicationId | 无 | 申请详情及版本 |
| POST /applications | positionId、name、education、school、phone、email、owner、skills、experience、note、appliedDate | 新申请回执 |
| PATCH /applications/:applicationId | 上述资料字段，职位 ID 固定 | 更新回执 |
| GET /applications/:applicationId/advance/preflight | 无 | 下一阶段与缺评决策资格 |
| POST /applications/:applicationId/advance | targetStage、符合规则时 reason | 只允许合法下一阶段 |
| GET /applications/:applicationId/advancement/history | 无 | 晋级事件数组 |
| GET /interviews | applicationId、positionId、stageScope、status、limit、offset | 面试分页，无周起止参数 |
| GET /interviews/:interviewId | 无 | 面试详情 |
| GET /applications/:applicationId/interviews | 无 | 该申请面试数组 |
| POST /applications/:applicationId/interviews | scheduledAt、interviewerName、note | 预约回执 |
| POST /applications/:applicationId/interviews/:interviewId/reschedule | interviewVersion、scheduledAt | 改期回执 |
| POST /applications/:applicationId/interviews/:interviewId/complete | interviewVersion | 完成回执，阶段保持 |
| POST /applications/:applicationId/interviews/:interviewId/cancel | interviewVersion、reason | 取消回执 |
| GET /applications/:applicationId/feedback | 无 | 面评数组 |
| GET /applications/:applicationId/interviews/:interviewId/supplement-eligibility | 无 | 历史补评资格 |
| GET /applications/:applicationId/feedback/:feedbackId/history | 无 | 面评历史及前后快照 |
| POST /applications/:applicationId/interviews/:interviewId/feedback | reviewerName、recommendation、reason | 面评回执 |
| POST /applications/:applicationId/interviews/:interviewId/feedback/supplement | 同上 | 仅允许符合资格的历史补评 |
| POST /applications/:applicationId/interviews/:interviewId/feedback/correct | 同上、feedbackRevision、correctionReason | 有痕更正 |
| GET /applications/:applicationId/offer | 无 | 生命周期、阶段、Offer 状态和结果 |
| GET /applications/:applicationId/offer/preflight | 无 | 现有 Offer 动作资格 |
| POST /applications/:applicationId/offer/send | 通用版本字段 | 发送回执 |
| POST /applications/:applicationId/offer/accept | 通用版本字段 | 接受回执，录用另行确认 |
| POST /applications/:applicationId/offer/decline | reason | 拒绝及相应结案回执 |
| POST /applications/:applicationId/offer/confirm-hire | reason | 录用回执 |
| GET /applications/:applicationId/offer/history | 无 | Offer 及结案历史数组 |
| GET /applications/:applicationId/closure/preflight | 无 | 合法结案选项 |
| POST /applications/:applicationId/close | outcome、reason | 合法结案回执 |
| GET /applications/:applicationId/history | limit、eventType、afterOccurredAt、afterEventId | 带当前位置与游标的事件页 |
| GET /positions/:positionId/history | 同上 | 职位事件页 |
| GET /applications/:applicationId/historical-missing | 无 | 真实历史缺评映射 |
| GET /legacy-records/list | limit、offset、entityType、mappingStatus、sourceKey | 只读旧档索引页 |
| GET /legacy-records | sourceKey、entityType、legacyId | 原始归档映射、已知事实和导入时间 |

常见错误包括无效输入 400、认证失败 401、权限不足 403、资源缺失 404、版本或幂等冲突 409、请求体超限 413、媒体类型错误 415，以及服务器故障 500。错误使用 `{error:{code,message,requestId}}`，请求 ID 也在 X-Request-Id 响应头返回。精确字段、枚举和状态以 `server/routes/*-v3.js`、`server/middleware/{auth-v3,error-v3}.js`、`server/services` 以及 `src/api` 为准。

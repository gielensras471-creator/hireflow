# V4 技术架构

产品 V4.0.0 冻结候选沿用业务接口 `/api/v3`。

| 层 | 实际模块 |
| --- | --- |
| 入口 | `src/main.ts` 和 `vite.config.ts` 按模式接入 Vue 应用、Pinia 及对应路由。普通兼容构建保留旧页面与请求链。 |
| 导航 | `src/router/v3.ts` 负责鉴权、深链与草稿离开守卫，`src/router/v3-navigation.ts` 定义导航关系，`src/layouts/V3Shell.vue` 管理身份隔离的工作标签、内容滚动和焦点恢复。 |
| 页面 | `src/views` 负责工作台、业务列表和详情，`src/components` 承载可复用表单、日历、看板和业务操作。 |
| 状态 | Pinia 用于兼容应用的共享状态。现行 V3 会话由 `src/utils/auth-v3.ts` 的响应式会话对象管理，业务视图用 Vue 本地状态及专用工具管理请求代次。 |
| 偏好和样式 | `src/utils/v4-work-preferences.ts` 按身份和运行模式管理浏览器偏好，显式路由恢复优先。壳层和页面样式分布在 `src/styles/_v4-shell.scss`、`v3.scss` 与各模块 Sass。 |
| API | `src/api/request-v3.ts` 封装 Axios、Bearer、错误归一化和过期请求隔离，领域文件管理 DTO 及写入意图。 |
| 后端 | `server/index-v3.js` 启动正式实例，`server/index-demo-v3.js` 启动内存 Demo。两者挂载 `server/app-v3.js` 的 Express API。请求上下文与 CORS 之后是 16 KiB JSON 解析，再进入路由认证和权限检查。 |
| 持久化 | `server/services` 承担业务资格与 SQL，`command-core.js` 管理事务、幂等回执及真实事件。正式模式打开既有受控 SQLite，Demo 新建内存库并构造虚构数据。 |

## 关键请求链

1. **登录与身份恢复**。 `V3Login.vue` 调用 `request-v3.ts` 的 `v3Session`。 `createV3Session` 发起登录并请求 `/auth/me`。 `server/middleware/auth-v3.js` 核验 bcrypt 密码，使用认证版本签发 JWT，再按用户 ID 核对数据库身份、角色和认证版本。确认身份后按用户选择持久化，路由守卫刷新时恢复，临时网络失败允许重试。过期或失效时清除会话，旧响应受会话代次约束。
2. **HR 推进阶段**。 `V3AdvancementPanel.vue` 使用 `advancement-v3.ts` 的资格读取与写入意图。 `decision-v3.js` 先检查认证和招聘权限，再用 `commandRequest` 解码版本及幂等键。 `createAdvancementService` 复核下一阶段、待处理面试及缺评原因。 `createCommandCore` 在同一事务写入申请变更、事件、缺评关联和回执，返回服务器事实。前端按结果刷新资格、状态和历史。
3. **更改密码及旧会话撤销**。 `V3Placeholder.vue` 经 `updateOwnPassword` 发出 `PATCH /auth/me/password`。正式账号由 `auth-v3.js` 验证当前密码、新密码及当次角色。条件更新原认证版本和密码散列并原子递增 `auth_version`，成功返回 204，前端清空当前身份并返回登录。其他旧 JWT 下一次请求时因数据库版本不匹配而被拒绝。共享 Demo 拒绝账户写入。
